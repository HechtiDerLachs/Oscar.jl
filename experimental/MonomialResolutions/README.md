# Monomial resolutions

## Aims

Computation of sheaf cohomology on toric varieties requires to know the so-called "support sets". The most efficient way to compute these is in [EisenbudMustataStillman2000](@cite), Corollary 1.2 (c). This requires a resolution of a squarefree monomial ideal -- a rather special case which allows for a lot of optimization beyond the standard algorithms. This is an attempt to explore such optimizations, starting from the encoding of the exponent vectors as bit-vectors, etc.
